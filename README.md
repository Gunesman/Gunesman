## 🧭 My Path

```
Mining Engineering  →  10+ years in Airport Cargo Logistics (Belgium)  →  Data Analytics  →  Data Science / ML
```

I spent over a decade coordinating cargo operations at Aviapartner Belgium — reading manifests, solving operational bottlenecks under time pressure, and making decisions with incomplete data in real time. Turns out that's a pretty good training ground for data analysis. Now I'm formalizing that instinct with Python, statistics, and machine learning.
